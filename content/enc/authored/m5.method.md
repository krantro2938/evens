# Линейные операторы — как решать

## Проверка линейности отображения
1. Проверить $f(x+y) = f(x)+f(y)$.
2. Проверить $f(\alpha x) = \alpha f(x)$.
3. Если хотя бы одно нарушается (например, есть свободный член,
   модуль, квадрат координаты) → оператор нелинейный.

## Матрица оператора в базисе
- Применить оператор к каждому базисному вектору $e_i$, разложить
  результат $f(e_i)$ по тому же базису — координаты идут в $i$-й
  столбец матрицы $A$.
- Координаты образа: $[f(x)] = A[x]$.

## Матрица оператора при замене базиса
- Если $T$ — матрица перехода от старого базиса к новому, то
  $$
  A' = T^{-1} A T
  $$
- Задача "найти матрицу в базисе из собственных векторов" → это и есть
  переход к диагональному виду, см. m6.

## Образ и ядро оператора
- Ядро $\ker f$: решить однородную систему $Ax = 0$ — пространство
  решений и есть ядро; $\dim \ker f$ = число свободных переменных.
- Образ $\operatorname{im} f$: линейная оболочка столбцов матрицы $A$;
  $\dim \operatorname{im} f = \operatorname{rang} A$.
- Проверка: $\dim \ker f + \dim \operatorname{im} f = \dim V$
  (теорема о ранге и дефекте).

## Действия с операторами
- Сумма/произведение операторов → сумма/произведение их матриц (в одном
  и том же базисе); произведение операторов, вообще говоря, не
  коммутативно.
- Обратный оператор существует $\iff$ $\det A \ne 0$; матрица обратного
  оператора — $A^{-1}$.

## Классификация по типу задачи
- "Найти матрицу оператора по формуле образа" → пункт "Матрица оператора
  в базисе".
- "Оператор проектирования / отражения / поворота на плоскости" →
  выписать матрицу по геометрическому смыслу в стандартном базисе, затем
  работать с ней как с обычной матрицей.
- "Матрица в новом базисе" → формула $A' = T^{-1}AT$.

## Проверка
- $A e_i$ должно совпадать со столбцом $i$ матрицы $A$ по построению.
- Для найденного ядра — подставить базисный вектор ядра в $Ax$, должен
  получиться нулевой вектор.
- $\operatorname{rang} A$ (образ) плюс размерность ядра равны размерности
  пространства — арифметическая проверка.
