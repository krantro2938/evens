# Линейные пространства — как решать

## Проверка: является ли множество линейным пространством
1. Проверить замкнутость относительно сложения: сумма двух элементов
   множества снова лежит в нём.
2. Проверить замкнутость относительно умножения на скаляр.
3. Если хоть одна операция выводит за пределы множества (типичные
   ловушки: условие вида $x_1=1$, $x_1\ge0$, $x_1x_2=0$) → не
   пространство.
4. Если обе выполняются — остальные аксиомы (ассоциативность и т.д.)
   обычно наследуются от объемлющего пространства, отдельно не
   проверяют.

## Проверка линейной зависимости системы векторов
- Составить матрицу из векторов как строк (или столбцов), найти её
  ранг элементарными преобразованиями.
- Ранг = число векторов → линейно независимы.
- Ранг < числа векторов → линейно зависимы; количество "лишних"
  векторов = число векторов минус ранг.
- Альтернатива для $n$ векторов в $n$-мерном пространстве → вычислить
  определитель матрицы из них; $\ne 0$ → независимы, $=0$ → зависимы.

## Нахождение базиса и размерности
- Дано линейное подпространство как множество решений однородной
  системы $Ax=0$ → решить систему методом Гаусса, выразить через
  свободные переменные, векторы при свободных переменных — базис
  (ФСР), их число = $\dim = n - \operatorname{rang} A$.
- Дано подпространство как линейная оболочка векторов
  $L=\langle v_1,\dots,v_k\rangle$ → найти ранг системы $v_1,\dots,v_k$
  (как выше) — это и есть $\dim L$; любая максимальная линейно
  независимая подсистема — базис.

## Координаты вектора в базисе
1. Составить уравнение $x = c_1e_1+\dots+c_ne_n$ покоординатно.
2. Решить получившуюся систему относительно $c_1,\dots,c_n$ (методом
   Гаусса или через обратную матрицу из базисных векторов-столбцов).

## Матрица перехода между базисами
- Даны старый базис $e$ и новый $e'$, каждый $e'_j$ разложен по $e$ →
  столбцы матрицы перехода $T$ — это координаты $e'_j$ в базисе $e$.
- Пересчёт координат вектора: если $[x]_e$ известны, а нужны $[x]_{e'}$
  → $[x]_{e'} = T^{-1}[x]_e$.

## Сумма и пересечение подпространств
- $\dim(L_1+L_2) = \dim L_1 + \dim L_2 - \dim(L_1\cap L_2)$ (формула
  Грассмана) — использовать для проверки или для нахождения одной из
  величин по трём известным.
- Найти $L_1\cap L_2$ явно → объединить системы уравнений, задающих оба
  подпространства, решить совместно.
- Найти $L_1+L_2$ явно → объединить порождающие векторы обоих
  подпространств в одну систему, найти в ней базис (см. выше).
- Сумма прямая ($L_1\oplus L_2$) $\iff$ $L_1\cap L_2=\{0\}$.

## Проверка
- Подставить найденные координаты $c_i$ обратно в разложение по базису
  — должен получиться исходный вектор.
- Число базисных векторов подпространства должно совпадать с
  вычисленной размерностью.
- Формулу Грассмана проверить численно на найденных размерностях.
