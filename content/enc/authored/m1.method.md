# Комплексные числа — как решать

## Формы записи — когда какая удобна
- Сложение, вычитание → алгебраическая форма $z = x + iy$.
- Умножение, деление, степени → тригонометрическая или показательная: $z = r(\cos\varphi + i\sin\varphi) = re^{i\varphi}$.
- Извлечение корня $\sqrt[n]{z}$ → только показательная форма.

## Модуль и аргумент
- $r = |z| = \sqrt{x^2+y^2}$.
- $\varphi = \arg z$: смотреть по четверти, $\operatorname{tg}\varphi = y/x$.
  - 1-я четверть: $\varphi = \operatorname{arctg}(y/x)$.
  - 2-я: $\varphi = \pi - \operatorname{arctg}(y/|x|)$.
  - 3-я: $\varphi = \pi + \operatorname{arctg}(|y|/|x|)$.
  - 4-я: $\varphi = -\operatorname{arctg}(|y|/x)$.

## Операции — процедура
1. Даны $z$ в алгебраической форме, нужна степень $z^n$ при $n \ge 3$ →
   перевести в показательную форму, применить формулу Муавра
   $z^n = r^n e^{in\varphi}$, вернуться в алгебраическую при необходимости.
2. Нужен корень $\sqrt[n]{z}$ → перевести в показательную форму, применить
   $$
   \sqrt[n]{z} = \sqrt[n]{r}\left(\cos\frac{\varphi+2\pi k}{n} + i\sin\frac{\varphi+2\pi k}{n}\right), \quad k=0,\dots,n-1
   $$
   получить все $n$ значений, отметить их на окружности радиуса $\sqrt[n]{r}$.
3. Деление $z_1/z_2$ в алгебраической форме → умножить числитель и
   знаменатель на сопряжённое $\bar z_2$.
4. Уравнение $z^n = a$ → это частный случай корня из числа $a$.
5. Квадратное уравнение с комплексными корнями (дискриминант $< 0$) →
   обычная формула корней, $\sqrt{D}$ понимать как $i\sqrt{|D|}$.

## Геометрия на плоскости
- $|z - z_0| = r$ → окружность с центром $z_0$.
- $|z - z_1| = |z - z_2|$ → серединный перпендикуляр отрезка $z_1 z_2$.
- $\arg(z - z_0) = \alpha$ → луч из точки $z_0$.

## Проверка
- Возвести найденный корень $\sqrt[n]{z}$ обратно в степень $n$ — должно
  получиться исходное $z$.
- Модуль результата умножения/деления — произведение/частное модулей,
  аргумент — сумма/разность аргументов; сверить отдельно.
