# Кратные, криволинейные и поверхностные интегралы — как решать

## Двойной интеграл — порядок действий
1. Изобразить область $D$, определить её границы по $x$ и по $y$.
2. Выбрать порядок интегрирования — тот, где границы описываются проще
   (одна из двух расстановок обычно даёт не более двух кусков области).
3. Расставить пределы: внешний интеграл — по константам, внутренний — по
   функциям другой переменной.
4. Если подынтегральная функция или область имеет вид $x^2+y^2$ (круг,
   кольцо) → перейти в полярные координаты $x=r\cos\varphi,\ y=r\sin\varphi$,
   добавить якобиан $r$:
   $$
   \iint_D f(x,y)\,dx\,dy = \iint_{D'} f(r\cos\varphi,r\sin\varphi)\,r\,dr\,d\varphi
   $$

## Смена порядка интегрирования
- Восстановить область по заданным пределам (нарисовать), затем
  переписать её границы для другого порядка — часто область придётся
  разбить на несколько частей.

## Тройной интеграл — выбор координат
- Область — параллелепипед или произвольная без симметрии → декартовы
  координаты, повторное интегрирование по трём переменным.
- Область — цилиндр, конус, круглое основание → цилиндрические
  координаты $x=r\cos\varphi,\ y=r\sin\varphi,\ z=z$, якобиан $r$.
- Область — шар, часть шара → сферические координаты
  $x=r\sin\theta\cos\varphi,\ y=r\sin\theta\sin\varphi,\ z=r\cos\theta$,
  якобиан $r^2\sin\theta$.

## Криволинейный интеграл 1-го рода (по длине дуги)
- Кривая $y=y(x)$ → $dl=\sqrt{1+(y')^2}\,dx$, интегрировать по $x$.
- Кривая параметрически $x(t),y(t)$ →
  $dl=\sqrt{(x'_t)^2+(y'_t)^2}\,dt$.
- Не зависит от направления обхода кривой.

## Криволинейный интеграл 2-го рода (по координатам, работа поля)
- $\int_L P\,dx+Q\,dy$: параметризовать кривую, подставить $x(t),y(t)$
  и $dx=x'_t\,dt,\ dy=y'_t\,dt$, свести к обычному интегралу по $t$.
- Меняет знак при смене направления обхода.
- Если $\dfrac{\partial P}{\partial y}=\dfrac{\partial Q}{\partial x}$
  всюду в односвязной области → поле потенциально, интеграл не зависит
  от пути → искать потенциал $U$ ($dU=P\,dx+Q\,dy$) и считать как
  $U(B)-U(A)$, не интегрируя по кривой напрямую.

## Формула Грина — когда применять
- Замкнутый контур $L$ (обход против часовой стрелки = положительный)
  → свести криволинейный интеграл к двойному по области $D$, которую он
  ограничивает:
  $$
  \oint_L P\,dx+Q\,dy = \iint_D\left(\frac{\partial Q}{\partial x}-\frac{\partial P}{\partial y}\right)dx\,dy
  $$
- Удобно, когда область $D$ проще самого контура (или наоборот — чтобы
  избежать вычисления контурного интеграла напрямую).

## Поверхностные интегралы
- 1-го рода (по площади поверхности, скаляр) → поверхность
  $z=z(x,y)$, $dS=\sqrt{1+(z'_x)^2+(z'_y)^2}\,dx\,dy$, свести к
  двойному интегралу по проекции на плоскость $xy$.
- 2-го рода (поток векторного поля через ориентированную поверхность) →
  выбрать сторону поверхности (нормаль), выразить $\cos\alpha,\cos\beta,\cos\gamma$
  через $z'_x,z'_y$, свести к двойному интегралу по проекции.

## Формула Остроградского — Гаусса
- Замкнутая поверхность $S$, поток наружу → заменить на тройной интеграл
  по объёму $V$, ограниченному $S$:
  $$
  \oiint_S P\,dydz+Q\,dzdx+R\,dxdy = \iiint_V\left(\frac{\partial P}{\partial x}+\frac{\partial Q}{\partial y}+\frac{\partial R}{\partial z}\right)dV
  $$

## Формула Стокса
- Циркуляция по замкнутому пространственному контуру $L$, ограничивающему
  поверхность $S$ → свести к потоку ротора через $S$:
  $$
  \oint_L P\,dx+Q\,dy+R\,dz = \iint_S \operatorname{rot}\vec F\cdot d\vec S
  $$

## Опознание задачи по формулировке
- "Масса пластинки с плотностью $\rho(x,y)$" → двойной интеграл
  $\iint_D \rho\,dx\,dy$.
- "Масса тела с плотностью $\rho(x,y,z)$" → тройной интеграл.
- "Работа силы вдоль пути" → криволинейный интеграл 2-го рода.
- "Поток поля через поверхность" → поверхностный интеграл 2-го рода.
- "Площадь / объём" → см. m14 и раздел про полярные/цилиндрические
  координаты выше.

## Проверка
- Оценить знак результата: если подынтегральная функция $\ge0$ на всей
  области — интеграл должен быть $\ge0$.
- В формуле Грина/Стокса/Остроградского — проверить вычисление обеими
  сторонами на простом частном случае (например, поле $P=x,\ Q=0$).
- Для полярных/сферических координат — не забыть якобиан ($r$ или
  $r^2\sin\theta$), частая ошибка на экзамене.
