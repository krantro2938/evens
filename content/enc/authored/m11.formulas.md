# Производные — формулы

## Определение
$$f'(x) = \lim_{\Delta x\to0}\frac{f(x+\Delta x)-f(x)}{\Delta x}$$

## Правила дифференцирования
$$(u\pm v)' = u'\pm v'$$
$$(uv)' = u'v+uv'$$
$$\left(\frac{u}{v}\right)' = \frac{u'v-uv'}{v^2}$$
$$(f(g(x)))' = f'(g(x))\,g'(x)$$
- Обратная функция: $\displaystyle (f^{-1})'(y) = \frac{1}{f'(x)}$

## Таблица производных
$$(x^\alpha)' = \alpha x^{\alpha-1}, \quad (\sqrt{x})' = \frac{1}{2\sqrt{x}}$$
$$(a^x)' = a^x\ln a, \quad (e^x)' = e^x$$
$$(\log_a x)' = \frac{1}{x\ln a}, \quad (\ln x)' = \frac1x$$
$$(\sin x)' = \cos x, \quad (\cos x)' = -\sin x$$
$$(\operatorname{tg} x)' = \frac{1}{\cos^2 x}, \quad (\operatorname{ctg} x)' = -\frac{1}{\sin^2 x}$$
$$(\arcsin x)' = \frac{1}{\sqrt{1-x^2}}, \quad (\arccos x)' = -\frac{1}{\sqrt{1-x^2}}$$
$$(\operatorname{arctg} x)' = \frac{1}{1+x^2}, \quad (\operatorname{arcctg} x)' = -\frac{1}{1+x^2}$$
$$(\operatorname{sh} x)' = \operatorname{ch} x, \quad (\operatorname{ch} x)' = \operatorname{sh} x$$

## Производные высших порядков
$$f^{(n)}(x) = \left(f^{(n-1)}(x)\right)'$$
$$(uv)^{(n)} = \sum_{k=0}^n \binom{n}{k} u^{(k)}v^{(n-k)}$$ (формула Лейбница)

## Дифференциал
$$dy = f'(x)\,dx$$
$$f(x_0+\Delta x) \approx f(x_0) + f'(x_0)\Delta x$$

## Формула Тейлора (с остатком Лагранжа)
$$f(x) = \sum_{k=0}^n \frac{f^{(k)}(x_0)}{k!}(x-x_0)^k + R_n(x)$$
$$R_n(x) = \frac{f^{(n+1)}(\xi)}{(n+1)!}(x-x_0)^{n+1}$$

## Правило Лопиталя
$$\lim\frac{f(x)}{g(x)} = \lim\frac{f'(x)}{g'(x)}$$ (для $\frac00$ или $\frac{\infty}{\infty}$)

## Исследование функции
- Возрастание: $f'(x)>0$; убывание: $f'(x)<0$
- Точка экстремума: $f'(x_0)=0$ (или не сущ.) и смена знака $f'$
- Выпуклость вниз: $f''(x)>0$; точка перегиба: $f''(x_0)=0$ со сменой знака

## Кривизна плоской кривой
$$k = \frac{|y''|}{(1+y'^2)^{3/2}}$$
