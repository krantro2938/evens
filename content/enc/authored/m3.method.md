# Линии и поверхности 2-го порядка — как решать

## Приведение линии к каноническому виду
1. Есть член $Bxy$ ($B \ne 0$) → сначала повернуть оси, чтобы избавиться
   от него (см. ниже), затем переносить начало координат.
2. Нет члена $xy$ → выделить полные квадраты по $x$ и по $y$ отдельно,
   получить перенос начала координат в центр (для эллипса/гиперболы) или
   в вершину (для параболы).
3. Сравнить итоговый вид с таблицей канонических уравнений и назвать
   кривую.

## Поворот осей при наличии $xy$
- Угол поворота $\alpha$ находится из
  $$
  \operatorname{ctg} 2\alpha = \frac{A - C}{B}
  $$
  для формы $Ax^2 + Bxy + Cy^2 + \dots = 0$.
- Практичнее: составить характеристическое уравнение матрицы квадратичной
  части $\begin{pmatrix} A & B/2 \\ B/2 & C \end{pmatrix}$, найти
  собственные значения $\lambda_1, \lambda_2$ — это и есть коэффициенты
  при $x'^2, y'^2$ в повёрнутых осях.

## Определение типа по инвариантам (быстрый путь)
- Составить $\delta = AC - (B/2)^2$ (знак старших членов).
  - $\delta > 0$ → эллиптический тип (эллипс, точка, мнимый эллипс).
  - $\delta < 0$ → гиперболический тип (гипербола, пара пересекающихся
    прямых).
  - $\delta = 0$ → параболический тип (парабола, пара параллельных
    прямых, одна прямая).
- Дальше — вычислить полный (большой) определитель $\Delta$ матрицы
  $3\times 3$ (с учётом линейных членов и свободного члена): $\Delta = 0$
  → вырожденный случай (пара прямых, точка), $\Delta \ne 0$ →
  невырожденная кривая.

## Стандартные уравнения — что искать в задаче
- $\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}=1$ → эллипс, полуоси $a,b$,
  фокусы на большей оси, $c^2=a^2-b^2$ (при $a>b$), эксцентриситет
  $e=c/a$.
- $\dfrac{x^2}{a^2}-\dfrac{y^2}{b^2}=1$ → гипербола, асимптоты
  $y=\pm\frac{b}{a}x$, $c^2=a^2+b^2$, $e=c/a>1$.
- $y^2=2px$ → парабола, фокус $(p/2,0)$, директриса $x=-p/2$.

## Поверхности 2-го порядка — узнавание по уравнению
- Даны три квадрата с одинаковыми знаками → эллипсоид
  $\dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}+\dfrac{z^2}{c^2}=1$.
- Два знака "+", один "−", равно $1$ → однополостный гиперболоид.
- Один "+", два "−", равно $1$ → двуполостный гиперболоид.
- Равно $0$, знаки разные → конус.
- Один линейный член, два квадратичных того же знака → эллиптический
  параболоид $z = \dfrac{x^2}{a^2}+\dfrac{y^2}{b^2}$.
- Один линейный член, два квадратичных разных знаков → гиперболический
  параболоид (седло) $z = \dfrac{x^2}{a^2}-\dfrac{y^2}{b^2}$.

## Метод сечений — понять форму поверхности
1. Зафиксировать $z=h=\text{const}$, посмотреть, какая кривая получается
   на плоскости $x,y$ (эллипс/гипербола/пара прямых/пусто).
2. Повторить для $x=\text{const}$ и $y=\text{const}$.
3. Собрать общую картину по трём сериям сечений.

## Проверка
- Подставить координаты вершин/фокусов обратно в каноническое уравнение.
- Для поворота — проверить, что $\lambda_1\lambda_2 = \delta$ и
  $\lambda_1+\lambda_2 = A+C$ (след и определитель матрицы совпадают).
