# Собственные значения и векторы — как решать

## Основная процедура
1. Составить характеристическое уравнение
   $$
   \det(A - \lambda E) = 0
   $$
2. Решить его — корни $\lambda_i$ это собственные значения.
3. Для каждого $\lambda_i$ решить однородную систему
   $(A - \lambda_i E)x = 0$ — ненулевые решения это собственные векторы,
   отвечающие $\lambda_i$.
4. Собственное подпространство для $\lambda_i$ — пространство решений
   этой системы; его размерность = число свободных параметров.

## Приводится ли матрица к диагональному виду
- Число различных собственных значений равно $n$ (порядку матрицы) →
  всегда диагонализуема, собственные векторы образуют базис.
- Есть кратные корни → диагонализуема тогда и только тогда, когда для
  каждого $\lambda_i$ геометрическая кратность (размерность собственного
  подпространства) равна алгебраической кратности (кратности корня в
  характеристическом уравнении). Если меньше — жорданова форма, не
  диагональная.
- Матрица симметричная (вещественная) → всегда диагонализуема, причём
  ортогональным преобразованием (см. m8).

## Построение диагонализирующей замены
1. Найти собственные векторы, составить из них столбцы матрицы $T$.
2. Тогда $T^{-1}AT = \Lambda$, где $\Lambda$ — диагональная матрица из
   $\lambda_i$ в том же порядке, что и столбцы в $T$.
3. Если нужна ортогональная матрица (симметричная $A$) → собственные
   векторы для разных $\lambda_i$ уже ортогональны, внутри одного
   $\lambda_i$ — ортогонализовать по Граму — Шмидту, затем
   нормировать каждый столбец.

## Полезные соотношения (для проверки и для устного счёта)
- Сумма собственных значений = след матрицы: $\sum \lambda_i = \operatorname{tr} A$.
- Произведение собственных значений = определитель: $\prod \lambda_i = \det A$.
- Если $A$ треугольная (верхняя или нижняя) → собственные значения — это
  просто числа на главной диагонали.

## Приложения
- Возведение матрицы в большую степень $A^n$ → диагонализовать,
  $A^n = T\Lambda^n T^{-1}$, где $\Lambda^n$ — просто $\lambda_i^n$ по
  диагонали.
- Квадратичная форма, канонический вид → собственные значения матрицы
  формы дают коэффициенты канонического вида (см. m7).

## Проверка
- Подставить $\lambda_i$ обратно в $\det(A-\lambda E)$ — должно
  получиться $0$.
- Умножить $A$ на найденный собственный вектор $v$ — должно получиться
  $\lambda_i v$ (тот же вектор, умноженный на число).
- След и определитель матрицы должны совпадать с суммой и произведением
  всех $\lambda_i$.
