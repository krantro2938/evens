# Билинейные и квадратичные формы — как решать

## Матрица квадратичной формы
- Форма $q(x) = \sum_{i,j} a_{ij}x_ix_j$ → симметричная матрица $A$ с
  $A_{ii}$ = коэффициент при $x_i^2$, $A_{ij}=A_{ji}$ = половина
  коэффициента при $x_ix_j$ ($i\ne j$).

## Приведение к каноническому виду — какой метод
- Нужно быстро, без ортогональности → метод Лагранжа (выделение полных
  квадратов):
  1. Если есть $a_{11}\ne 0$ — сгруппировать все члены с $x_1$ в полный
     квадрат, вычесть лишнее, повторить для оставшихся переменных.
  2. Если все $a_{ii}=0$, но есть смешанный член $a_{ij}x_ix_j$ →
     сделать замену $x_i = y_i+y_j,\ x_j = y_i-y_j$, тогда появится
     квадрат, и перейти к пункту 1.
- Нужен канонический вид ортогональным преобразованием (сохраняющий
  длины, углы; типичное требование — "привести к главным осям") →
  найти собственные значения матрицы $A$ (см. m6) — они и есть
  коэффициенты канонического вида:
  $$
  q = \lambda_1 y_1^2 + \lambda_2 y_2^2 + \dots + \lambda_n y_n^2
  $$

## Определение знакоопределённости — критерий Сильвестра
1. Выписать угловые (главные) миноры $\Delta_1,\Delta_2,\dots,\Delta_n$
   матрицы $A$.
2. Все $\Delta_k > 0$ → форма положительно определена.
3. Знаки чередуются, начиная с минуса ($\Delta_1<0,\Delta_2>0,\dots$) →
   форма отрицательно определена.
4. Иначе, если все $\Delta_k \ne 0$, но условия выше не выполняются →
   знакопеременная.
5. Есть нулевые миноры → критерий Сильвестра не даёт ответа напрямую,
   смотреть по собственным значениям: все $\lambda_i \ge 0$ (с хотя бы
   одним $=0$) → положительно полуопределена, аналогично для
   отрицательно полуопределённой.
- Альтернатива без вычисления миноров: найти все $\lambda_i$ — все
  $>0$ → положительно определена; все $<0$ → отрицательно определена;
  разных знаков → знакопеременная.

## Закон инерции (если спрашивают про ранг/сигнатуру)
- Привести форму любым способом (Лагранж или ортогонально) к сумме
  квадратов — число положительных коэффициентов $p$, отрицательных $q$ и
  нулевых не зависит от способа приведения (закон инерции).
- Ранг формы = $p+q$; сигнатура = $p-q$.

## Типичная постановка "линия/поверхность 2-го порядка → определить тип"
- Выделить квадратичную часть уравнения, применить ортогональное
  приведение — знаки $\lambda_i$ сразу дают тип кривой/поверхности,
  см. m3.

## Проверка
- В каноническом виде число положительных/отрицательных/нулевых
  коэффициентов должно совпадать при методе Лагранжа и через собственные
  значения (закон инерции).
- Сумма коэффициентов канонического вида (ортогональным способом) равна
  следу $A$; произведение — определителю $A$, если ранг полный.
