# Функции нескольких переменных — как решать

## Частные производные
- $\dfrac{\partial f}{\partial x}$ → дифференцировать по $x$, считая
  все остальные переменные постоянными.
- Смешанная производная $\dfrac{\partial^2 f}{\partial x\partial y}$ →
  продифференцировать сначала по одной, потом по другой; при
  непрерывности вторых производных порядок не важен (теорема Шварца) —
  удобно выбрать более простой порядок.

## Дифференцируемость и полный дифференциал
- $df = \dfrac{\partial f}{\partial x}dx + \dfrac{\partial f}{\partial y}dy$
  — использовать для приближённых вычислений:
  $f(x_0+\Delta x, y_0+\Delta y) \approx f(x_0,y_0) + df$.

## Производная сложной функции (цепное правило для нескольких переменных)
- $z=f(x,y)$, где $x=x(t), y=y(t)$ →
  $$
  \frac{dz}{dt} = \frac{\partial f}{\partial x}\cdot\frac{dx}{dt} +
  \frac{\partial f}{\partial y}\cdot\frac{dy}{dt}
  $$
- $z=f(x,y)$, где $x=x(u,v), y=y(u,v)$ → та же формула с частными
  производными по $u$ (и отдельно по $v$).

## Неявная функция
- $F(x,y)=0$ задаёт $y(x)$ →
  $$
  y'_x = -\frac{F'_x}{F'_y}
  $$
- $F(x,y,z)=0$ задаёт $z(x,y)$ →
  $$
  z'_x = -\frac{F'_x}{F'_z}, \qquad z'_y = -\frac{F'_y}{F'_z}
  $$

## Экстремумы функции двух переменных — процедура
1. Найти критические точки: решить систему $f'_x=0,\ f'_y=0$.
2. Вычислить в каждой точке $A=f''_{xx},\ B=f''_{xy},\ C=f''_{yy}$,
   составить $D = AC - B^2$.
3. $D>0$ и $A>0$ → локальный минимум; $D>0$ и $A<0$ → локальный
   максимум; $D<0$ → седловая точка, экстремума нет; $D=0$ →
   нужно дополнительное исследование (метод не даёт ответа).

## Условный экстремум — метод множителей Лагранжа
1. Дана целевая функция $f(x,y)$ и связь $g(x,y)=0$.
2. Составить функцию Лагранжа $L = f + \lambda g$.
3. Решить систему $L'_x=0,\ L'_y=0,\ g(x,y)=0$ относительно $x,y,\lambda$.
4. Проверить характер найденных точек (по смыслу задачи, знаку
   приращения, или через второй дифференциал $L$ на касательной к связи).

## Наибольшее/наименьшее значение в замкнутой области
1. Найти критические точки внутри области (как для обычного экстремума).
2. Исследовать функцию отдельно на каждом участке границы (свести к
   функции одной переменной или использовать множители Лагранжа для
   границы, заданной уравнением связи).
3. Сравнить значения функции во всех найденных точках — наибольшее и
   наименьшее среди них и есть ответ.

## Градиент и производная по направлению
- $\nabla f = \left(\dfrac{\partial f}{\partial x}, \dfrac{\partial f}{\partial y}\right)$
  — направление наискорейшего роста.
- Производная по направлению единичного вектора $\vec l=(\cos\alpha,\cos\beta)$:
  $$
  \frac{\partial f}{\partial l} = f'_x\cos\alpha + f'_y\cos\beta
  $$

## Проверка
- Подставить найденную точку экстремума обратно в частные производные —
  должны обращаться в ноль.
- Для условного экстремума — проверить, что точка удовлетворяет связи
  $g(x,y)=0$.
- Сравнить значение функции в подозреваемой точке максимума/минимума с
  соседними точками из той же области.
