# Евклидово пространство, ортогональные операторы — формулы

## Скалярное произведение (аксиомы)
$$(x,y)=(y,x), \quad (\alpha x,y)=\alpha(x,y)$$
$$(x+y,z)=(x,z)+(y,z), \quad (x,x)\ge 0,\ (x,x)=0 \iff x=0$$

## Норма и угол
$$\|x\| = \sqrt{(x,x)}$$
$$\cos\varphi = \frac{(x,y)}{\|x\|\,\|y\|}$$

## Неравенства
$$|(x,y)| \le \|x\|\,\|y\|$$ (Коши — Буняковского)
$$\|x+y\| \le \|x\|+\|y\|$$ (неравенство треугольника)

## Ортогональность, процесс Грама — Шмидта
$$e_1 = \frac{v_1}{\|v_1\|}$$
$$u_k = v_k - \sum_{i=1}^{k-1}(v_k,e_i)e_i, \quad e_k = \frac{u_k}{\|u_k\|}$$

## Ортогональная проекция
$$\operatorname{pr}_L x = \sum_i (x,e_i)e_i$$
$e_i$ — ортонормированный базис подпространства $L$

## Ортогональный оператор
$$(Ax,Ay) = (x,y) \ \forall x,y \iff A^TA = E$$
- Сохраняет длины и углы, $|\det A| = 1$
- Собственные значения: $|\lambda|=1$ (вещественные: $\pm1$)

## Ортогональная матрица
$$A^{-1} = A^T, \quad A^TA = AA^T = E$$
- Столбцы (и строки) образуют ортонормированную систему

## Самосопряжённый оператор
$$(Ax,y)=(x,Ay) \iff A = A^T$$
- Собственные значения вещественны, собственные векторы ортогональны
