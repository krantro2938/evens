# Комплексные числа — формулы

## Формы записи
- Алгебраическая: $z = x + iy$, $i^2 = -1$
- $x = \operatorname{Re} z$, $y = \operatorname{Im} z$
- Модуль: $r = |z| = \sqrt{x^2+y^2}$
- Аргумент: $\varphi = \arg z$, $\operatorname{tg}\varphi = y/x$
- Тригонометрическая: $z = r(\cos\varphi + i\sin\varphi)$
- Показательная: $z = re^{i\varphi}$

## Сопряжение и модуль
$$\bar z = x - iy, \quad z\bar z = |z|^2$$
$$|z_1 z_2| = |z_1||z_2|, \quad \left|\frac{z_1}{z_2}\right| = \frac{|z_1|}{|z_2|}$$
$$\overline{z_1+z_2} = \bar z_1+\bar z_2, \quad \overline{z_1 z_2} = \bar z_1 \bar z_2$$

## Действия в тригонометрической форме
$$z_1 z_2 = r_1 r_2\big(\cos(\varphi_1+\varphi_2)+i\sin(\varphi_1+\varphi_2)\big)$$
$$\frac{z_1}{z_2} = \frac{r_1}{r_2}\big(\cos(\varphi_1-\varphi_2)+i\sin(\varphi_1-\varphi_2)\big)$$

## Формула Муавра
$$z^n = r^n(\cos n\varphi + i\sin n\varphi)$$

## Корень степени $n$
$$\sqrt[n]{z} = \sqrt[n]{r}\left(\cos\frac{\varphi+2\pi k}{n} + i\sin\frac{\varphi+2\pi k}{n}\right)$$
$k = 0, 1, \dots, n-1$ — всего $n$ значений

## Формула Эйлера
$$e^{i\varphi} = \cos\varphi + i\sin\varphi$$
$$\cos\varphi = \frac{e^{i\varphi}+e^{-i\varphi}}{2}, \quad \sin\varphi = \frac{e^{i\varphi}-e^{-i\varphi}}{2i}$$
$$e^{i\pi} + 1 = 0$$

## Перевод между формами
$$x = r\cos\varphi, \quad y = r\sin\varphi$$
- $\varphi$ выбирается с учётом четверти $(x,y)$
