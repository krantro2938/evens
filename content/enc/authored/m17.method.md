# Дифференциальные уравнения — как решать

## Классификация уравнения 1-го порядка — первый шаг
Определить тип по виду $y'=f(x,y)$ или $M\,dx+N\,dy=0$, дальше — по
таблице ниже.

## С разделяющимися переменными
- Вид $y' = f(x)g(y)$ (или разделяется после преобразования) →
  разделить: $\dfrac{dy}{g(y)} = f(x)\,dx$, проинтегрировать обе части
  отдельно.

## Однородное уравнение
- Вид $y' = f(y/x)$ (правая часть зависит только от отношения $y/x$) →
  подстановка $y=ux$ ($u=u(x)$), тогда $y'=u+xu'$; уравнение сводится к
  уравнению с разделяющимися переменными относительно $u,x$.

## Линейное уравнение 1-го порядка
- Вид $y' + p(x)y = q(x)$ →
  1. Метод интегрирующего множителя: $\mu(x)=e^{\int p(x)\,dx}$,
     умножить уравнение на $\mu$, левая часть станет $(\mu y)'$,
     проинтегрировать.
  2. Или метод Бернулли (подстановка $y=uv$): подобрать $v$ так, чтобы
     обнулить часть уравнения, затем найти $u$.

## Уравнение Бернулли
- Вид $y' + p(x)y = q(x)y^n$, $n\ne0,1$ → подстановка $z=y^{1-n}$
  сводит уравнение к линейному относительно $z$.

## Уравнение в полных дифференциалах
- Вид $M(x,y)\,dx + N(x,y)\,dy=0$, проверить
  $\dfrac{\partial M}{\partial y} = \dfrac{\partial N}{\partial x}$ →
  если равенство выполняется, существует функция $U(x,y)$ с
  $dU=M\,dx+N\,dy$; найти её интегрированием $M$ по $x$ (с
  "константой" как функцией от $y$), уточнить через $N$; ответ
  $U(x,y)=C$.
- Равенство не выполняется, но уравнение похоже на такое → искать
  интегрирующий множитель $\mu(x)$ или $\mu(y)$, приводящий к равенству
  смешанных производных.

## Уравнения, допускающие понижение порядка (для уравнений 2-го порядка)
- Явно не содержит $y$: $F(x,y',y'')=0$ → подстановка $p=y'$, получить
  уравнение 1-го порядка на $p(x)$.
- Явно не содержит $x$: $F(y,y',y'')=0$ → подстановка $p=y'$, но $p$
  как функция от $y$: $y''=p\dfrac{dp}{dy}$.

## Линейные уравнения с постоянными коэффициентами (2-го порядка и выше)
1. Однородное $y''+py'+qy=0$: составить характеристическое уравнение
   $\lambda^2+p\lambda+q=0$.
   - Два различных вещественных корня $\lambda_1,\lambda_2$ →
     $y=C_1e^{\lambda_1x}+C_2e^{\lambda_2x}$.
   - Один корень кратности 2, $\lambda$ → $y=(C_1+C_2x)e^{\lambda x}$.
   - Комплексные корни $\alpha\pm i\beta$ →
     $y=e^{\alpha x}(C_1\cos\beta x+C_2\sin\beta x)$.
2. Неоднородное $y''+py'+qy=f(x)$: общее решение = общее решение
   однородного + частное решение неоднородного.
   - $f(x)$ — многочлен, экспонента, $\sin/\cos$ (или их произведение) →
     метод неопределённых коэффициентов: подобрать частное решение того
     же вида, что и $f(x)$; если "резонанс" (правая часть совпадает с
     решением однородного) → домножить пробное решение на $x$
     (или на $x^2$ при кратном корне).
   - $f(x)$ произвольного вида → метод вариации произвольных постоянных:
     $y=C_1(x)y_1+C_2(x)y_2$, где $y_1,y_2$ — решения однородного,
     $C_1'(x),C_2'(x)$ находятся из системы
     $C_1'y_1+C_2'y_2=0,\ C_1'y_1'+C_2'y_2'=f(x)$.

## Системы линейных уравнений с постоянными коэффициентами
- Свести к одному уравнению высшего порядка исключением переменных, либо
  искать решение в виде $\vec x = \vec v e^{\lambda t}$, где $\lambda$ —
  собственное значение матрицы системы, $\vec v$ — собственный вектор
  (см. m6).

## Опознание по формулировке задачи
- "Найти общее решение" → достаточно общего интеграла/решения с
  произвольными постоянными.
- "Найти решение задачи Коши" (даны $y(x_0)=y_0$, возможно и
  $y'(x_0)=y_1$) → сначала общее решение, затем подставить начальные
  условия и найти конкретные $C_1, C_2$.

## Проверка
- Подставить найденное $y(x)$ и его производные обратно в исходное
  уравнение — тождество должно выполняться.
- Для задачи Коши — проверить, что начальные условия действительно
  удовлетворяются при найденных $C_1,C_2$.
- Для линейного однородного — убедиться, что найденные $\lambda_i$ —
  корни характеристического уравнения (подставить обратно).
