# Неопределённые интегралы — как решать

## Опознать вид подынтегральной функции
- Правильная рациональная дробь $\dfrac{P(x)}{Q(x)}$ → разложить на
  простейшие дроби (по корням знаменателя), проинтегрировать каждую
  отдельно.
- Неправильная рациональная дробь (степень числителя $\ge$ степени
  знаменателя) → сначала выделить целую часть делением уголком, остаток
  — правильная дробь, разложить её.
- Произведение многочлена и $e^{ax}$, $\sin(ax)$, $\cos(ax)$ → по
  частям, $u$ = многочлен (понижает степень с каждым разом), $dv$ —
  остальное.
- Произведение $x^n$ и $\ln x$, $\arcsin x$, $\operatorname{arctg} x$ →
  по частям, $u$ = логарифм/обратная тригонометрическая функция.
- Содержит $\sqrt{a^2-x^2}$ → подстановка $x = a\sin t$.
- Содержит $\sqrt{a^2+x^2}$ → подстановка $x = a\operatorname{tg} t$.
- Содержит $\sqrt{x^2-a^2}$ → подстановка $x = a/\cos t$.
- Рациональная функция от $\sin x,\cos x$ → универсальная подстановка
  $t=\operatorname{tg}(x/2)$ (превращает интеграл в рациональную
  функцию от $t$); если функция нечётна по $\sin x$ → лучше
  $t=\cos x$; нечётна по $\cos x$ → $t=\sin x$; чётна по обоим →
  $t=\operatorname{tg} x$.
- $\sin^m x\cos^n x$ с нечётным $m$ или $n$ → отделить один множитель,
  оставшуюся чётную степень выразить через другую функцию
  ($\sin^2+\cos^2=1$).
- $\sin^m x\cos^n x$, оба показателя чётные и неотрицательные → формулы
  понижения степени.
- Иррациональность вида $R(x,\sqrt[n]{ax+b})$ → подстановка
  $t=\sqrt[n]{ax+b}$.
- Дробно-линейная иррациональность $R\!\left(x,\sqrt[n]{\dfrac{ax+b}{cx+d}}\right)$
  → подстановка $t=\sqrt[n]{\dfrac{ax+b}{cx+d}}$.

## Интегрирование по частям — формула и выбор
$$
\int u\,dv = uv - \int v\,du
$$
Правило выбора $u$ (мнемоника ЛИАТЭ — по убыванию приоритета для $u$):
логарифмическая, обратная тригонометрическая, алгебраическая (степенная),
тригонометрическая, экспоненциальная.

## Разложение рациональной дроби на простейшие
1. Разложить знаменатель на множители: линейные $(x-a)^k$ и
   квадратичные без вещественных корней $(x^2+px+q)^m$.
2. Каждому $(x-a)^k$ сопоставить сумму
   $\dfrac{A_1}{x-a}+\dfrac{A_2}{(x-a)^2}+\dots+\dfrac{A_k}{(x-a)^k}$.
3. Каждому $(x^2+px+q)^m$ сопоставить сумму слагаемых
   $\dfrac{B_ix+C_i}{(x^2+px+q)^i}$.
4. Найти коэффициенты методом неопределённых коэффициентов (приравнять
   многочлены) или подстановкой удобных значений $x$.
5. Проинтегрировать каждое простейшее слагаемое по табличным формулам.

## Табличные интегралы, которые проще запомнить, чем выводить
$$
\int \frac{dx}{x^2+a^2} = \frac1a\operatorname{arctg}\frac{x}{a}+C,
\qquad
\int \frac{dx}{\sqrt{a^2-x^2}} = \arcsin\frac{x}{a}+C
$$
$$
\int \frac{dx}{\sqrt{x^2\pm a^2}} = \ln\left|x+\sqrt{x^2\pm a^2}\right|+C
$$

## Проверка
- Продифференцировать полученную первообразную — должна получиться
  исходная подынтегральная функция.
- При разложении на простейшие — подставить контрольное значение $x$ в
  тождество числителей, сверить.
