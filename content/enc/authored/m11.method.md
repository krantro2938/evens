# Производные — как решать

## Базовая техника дифференцирования
- Сумма/разность → почленно: $(f\pm g)' = f'\pm g'$.
- Произведение → $(fg)' = f'g+fg'$.
- Частное → $\left(\dfrac{f}{g}\right)' = \dfrac{f'g-fg'}{g^2}$.
- Сложная функция → цепное правило $ (f(g(x)))' = f'(g(x))\cdot g'(x)$,
  применять последовательно "снаружи внутрь".

## Особые виды функций
- $y = f(x)^{g(x)}$ (степенно-показательная) → логарифмическое
  дифференцирование: прологарифмировать обе части,
  $\ln y = g(x)\ln f(x)$, продифференцировать неявно, затем домножить на
  $y$.
- Произведение/частное многих множителей → тоже логарифмическое
  дифференцирование удобнее прямого произведения.
- $y(x)$ задана неявно уравнением $F(x,y)=0$ → дифференцировать обе
  части по $x$, помня, что $y=y(x)$, выразить $y'$.
- $x=x(t),\ y=y(t)$ параметрически → $y'_x = \dfrac{y'_t}{x'_t}$.

## Производные высших порядков
- Вторая производная параметрически заданной функции →
  $$
  y''_{xx} = \frac{(y'_x)'_t}{x'_t}
  $$
  (не путать с $\dfrac{y''_{tt}}{x''_{tt}}$ — это неверно).
- $n$-я производная стандартной функции → искать закономерность на
  первых 2–3 производных или применять формулу Лейбница для произведения:
  $$
  (uv)^{(n)} = \sum_{k=0}^{n}\binom{n}{k}u^{(k)}v^{(n-k)}
  $$

## Приложения производной — по формулировке задачи
- "Уравнение касательной в точке $x_0$" →
  $y = f(x_0) + f'(x_0)(x-x_0)$.
- "Уравнение нормали" → $y = f(x_0) - \dfrac{1}{f'(x_0)}(x-x_0)$.
- "Исследовать на монотонность" → найти $f'$, решить неравенства
  $f'>0$ и $f'<0$.
- "Найти экстремумы" → найти критические точки ($f'=0$ или не
  существует), проверить смену знака $f'$ (или знак $f''$ в точке).
- "Найти точки перегиба" → решить $f''=0$, проверить смену знака $f''$.
- "Найти наибольшее/наименьшее значение на отрезке $[a,b]$" → сравнить
  значения $f$ в критических точках внутри отрезка и на концах $a,b$.
- "Приближённо вычислить значение" → дифференциал:
  $f(x_0+\Delta x)\approx f(x_0)+f'(x_0)\Delta x$.

## Проверка
- Продифференцировать результат ещё раз обратной операцией там, где
  возможно (например, для неявной функции — подставить в исходное
  $F(x,y)=0$, взять $dy/dx$ независимым способом).
- В точке экстремума знак $f'$ действительно должен меняться, иначе это
  не экстремум (например, для $f'=0$, но $f''\ne0$ проверить отдельно).
