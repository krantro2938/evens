# Дифференциальные уравнения — формулы

## ДУ 1-го порядка с разделяющимися переменными
$$f_1(x)g_1(y)\,dx + f_2(x)g_2(y)\,dy = 0$$
$$\int \frac{f_1(x)}{f_2(x)}dx + \int \frac{g_2(y)}{g_1(y)}dy = C$$

## Однородное ДУ
$$y' = f\left(\frac{y}{x}\right), \quad y=ux \Rightarrow u'x+u = f(u)$$

## Линейное ДУ 1-го порядка
$$y' + p(x)y = q(x)$$
$$y = e^{-\int p\,dx}\left(\int q(x)e^{\int p\,dx}dx + C\right)$$
- Метод: подстановка $y=uv$, или метод вариации постоянной

## Уравнение Бернулли
$$y' + p(x)y = q(x)y^n \quad (n\ne0,1)$$
- Замена $z=y^{1-n}$ сводит к линейному

## Уравнение в полных дифференциалах
$$P(x,y)dx+Q(x,y)dy=0, \quad P'_y=Q'_x$$
$$u(x,y)=C, \quad du = P\,dx+Q\,dy$$

## Линейные ДУ высших порядков с пост. коэфф. (однородные)
$$y^{(n)} + a_{n-1}y^{(n-1)} + \dots + a_0 y = 0$$
$$k^n + a_{n-1}k^{n-1} + \dots + a_0 = 0$$ (характеристическое уравнение)
- Действительный корень $k$: $e^{kx}$
- Кратный корень $k$ (кратн. $m$): $e^{kx}, xe^{kx}, \dots, x^{m-1}e^{kx}$
- Комплексные $k=\alpha\pm i\beta$: $e^{\alpha x}\cos\beta x,\ e^{\alpha x}\sin\beta x$

## ЛОДУ 2-го порядка — общее решение
$$y = C_1 y_1 + C_2 y_2$$

## Неоднородное ЛДУ
$$y = y_{odn} + y_{chastn}$$
- Подбор частного решения по виду правой части $f(x)$:
$$f(x)=P_m(x)e^{\alpha x} \Rightarrow y_{ch}=x^s Q_m(x)e^{\alpha x}$$
$s$ — кратность $\alpha$ как корня характеристич. уравнения

## Метод Лагранжа (вариация постоянных)
$$y = C_1(x) y_1 + C_2(x) y_2$$
$$C_1'y_1+C_2'y_2=0, \quad C_1'y_1'+C_2'y_2' = f(x)$$

## Линейная система ДУ (нормальная форма)
$$\vec x' = A\vec x, \quad \vec x = \sum_i C_i e^{\lambda_i t}\vec v_i$$
$\lambda_i, \vec v_i$ — собственные значения/векторы $A$
