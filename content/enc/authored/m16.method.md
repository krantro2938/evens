# Ряды — как решать

## Числовой ряд — с чего начать
1. Проверить необходимый признак: $\lim_{n\to\infty} a_n = 0$?
   Если нет (или предел не существует) → ряд расходится, дальше можно
   не проверять.
2. Если предел равен $0$ — это не доказывает сходимость, нужен один из
   признаков ниже.

## Выбор признака сходимости для знакоположительного ряда
- Ряд похож по виду на эталонный (степенной $\sum 1/n^p$, геометрический
  $\sum q^n$) → признак сравнения: найти $b_n$ того же порядка роста,
  сравнить $a_n$ и $b_n$ (или предельная форма
  $\lim a_n/b_n = c$, $0<c<\infty$ → ряды ведут себя одинаково).
- В общем члене есть факториалы или $c^n$ → признак Даламбера:
  $$
  \lim_{n\to\infty}\frac{a_{n+1}}{a_n} = L
  $$
  $L<1$ → сходится, $L>1$ → расходится, $L=1$ → признак не работает,
  пробовать другой.
- Общий член содержит $n$-ю степень целиком ($a_n = (\dots)^n$) →
  радикальный признак Коши:
  $$
  \lim_{n\to\infty}\sqrt[n]{a_n} = L
  $$
  та же интерпретация $L$, что и у Даламбера.
- Общий член — значение монотонной убывающей положительной функции
  $f(n)$, интеграл от которой легко берётся → интегральный признак Коши:
  ряд $\sum f(n)$ сходится $\iff$ сходится $\int_1^{\infty}f(x)\,dx$.
- Эталон для сравнения: $\sum \dfrac1{n^p}$ сходится при $p>1$,
  расходится при $p\le1$; геометрический $\sum q^n$ сходится при
  $|q|<1$.

## Знакочередующиеся ряды — признак Лейбница
- Ряд вида $\sum(-1)^n b_n$, $b_n>0$ →
  сходится, если $b_n$ монотонно убывает к $0$ ($b_n\to0$ и
  $b_{n+1}\le b_n$).
- Оценка остатка: $|R_n| \le b_{n+1}$ (следующий по модулю член).

## Абсолютная и условная сходимость
1. Составить ряд из модулей $\sum |a_n|$, применить один из признаков
   выше для знакоположительного ряда.
2. Сходится $\sum|a_n|$ → исходный ряд сходится абсолютно.
3. $\sum|a_n|$ расходится, но исходный ряд сходится (например, по
   Лейбницу) → сходится условно.

## Функциональные и степенные ряды
- Найти область сходимости функционального ряда → применить признак
  Даламбера/Коши к $|a_n(x)|$, решить неравенство $L(x)<1$ относительно
  $x$; отдельно исследовать границы найденного интервала подстановкой.
- Степенной ряд $\sum a_n(x-x_0)^n$ → радиус сходимости
  $$
  R = \lim_{n\to\infty}\left|\frac{a_n}{a_{n+1}}\right|
  $$
  либо, что то же самое,
  $$
  R = \frac{1}{\lim\sqrt[n]{|a_n|}}
  $$
  интервал сходимости $(x_0-R,\ x_0+R)$, концы проверять отдельно
  подстановкой в исходный числовой ряд.

## Разложение функции в ряд Тейлора / Маклорена
1. Если функция — комбинация стандартных функций ($e^x$, $\sin x$,
   $\cos x$, $\ln(1+x)$, $(1+x)^\alpha$) → взять готовое разложение и
   подставить/домножить/сложить, не дифференцировать заново.
2. Если функция нестандартная → вычислить $f(x_0), f'(x_0), f''(x_0),\dots$
   и подставить в
   $$
   f(x) = \sum_{n=0}^{\infty}\frac{f^{(n)}(x_0)}{n!}(x-x_0)^n
   $$
3. Использовать разложение для приближённого вычисления → взять первые
   несколько членов, оценить погрешность через следующий отброшенный
   член (или через остаточный член в форме Лагранжа).

## Ряд Фурье
- Функция периода $2\pi$, нужно разложение по $\sin,\cos$ →
  $$
  a_0=\frac1\pi\int_{-\pi}^{\pi}f(x)\,dx,\quad
  a_n=\frac1\pi\int_{-\pi}^{\pi}f(x)\cos nx\,dx,\quad
  b_n=\frac1\pi\int_{-\pi}^{\pi}f(x)\sin nx\,dx
  $$
- Функция чётная → все $b_n=0$, использовать только косинусы, интеграл
  по $[0,\pi]$ с множителем $2$.
- Функция нечётная → все $a_n=0$, аналогично только синусы.
- Разложение на произвольном отрезке $[-l,l]$ → те же формулы с заменой
  $\cos nx\to\cos\dfrac{n\pi x}{l}$ и периодом $2l$.

## Проверка
- Необходимый признак — если $a_n\not\to0$, сразу отбросить остальные
  проверки, ряд расходится.
- Численно просуммировать первые несколько членов ряда и посмотреть,
  стабилизируется ли частичная сумма (для сходящегося ряда).
- Радиус сходимости степенного ряда — подставить середину найденного
  интервала, убедиться, что общий член убывает.
