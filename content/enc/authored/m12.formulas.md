# Функции нескольких переменных — формулы

## Частные производные
$$f'_x = \frac{\partial f}{\partial x} = \lim_{\Delta x\to0}\frac{f(x+\Delta x,y)-f(x,y)}{\Delta x}$$
$$f''_{xy} = \frac{\partial^2 f}{\partial x\,\partial y}$$
- Теорема Шварца: $f''_{xy} = f''_{yx}$ (при непрерывности)

## Полный дифференциал
$$dz = \frac{\partial z}{\partial x}dx + \frac{\partial z}{\partial y}dy$$
$$d^2z = z''_{xx}dx^2 + 2z''_{xy}dx\,dy + z''_{yy}dy^2$$

## Производная сложной функции
$$\frac{dz}{dt} = \frac{\partial z}{\partial x}\frac{dx}{dt} + \frac{\partial z}{\partial y}\frac{dy}{dt}$$

## Градиент и производная по направлению
$$\operatorname{grad} f = \left(\frac{\partial f}{\partial x}, \frac{\partial f}{\partial y}, \frac{\partial f}{\partial z}\right)$$
$$\frac{\partial f}{\partial l} = (\operatorname{grad} f, \vec e_l) = f'_x\cos\alpha+f'_y\cos\beta+f'_z\cos\gamma$$
- $\vec e_l$ — единичный вектор направления, наибольший рост — вдоль $\operatorname{grad} f$

## Касательная плоскость и нормаль
$$z-z_0 = f'_x(x_0,y_0)(x-x_0) + f'_y(x_0,y_0)(y-y_0)$$
$$\frac{x-x_0}{f'_x} = \frac{y-y_0}{f'_y} = \frac{z-z_0}{-1}$$ (нормаль)

## Неявная функция
$$y'_x = -\frac{F'_x}{F'_y}, \quad F(x,y)=0$$

## Экстремумы функции двух переменных
- Необходимое условие: $f'_x=0,\ f'_y=0$
$$\Delta = f''_{xx}f''_{yy} - (f''_{xy})^2$$
- $\Delta>0,\ f''_{xx}>0$ — минимум; $\Delta>0,\ f''_{xx}<0$ — максимум
- $\Delta<0$ — не экстремум; $\Delta=0$ — нужен доп. анализ

## Условный экстремум (метод Лагранжа)
$$L(x,y,\lambda) = f(x,y) + \lambda\,\varphi(x,y)$$
$$L'_x=0,\quad L'_y=0,\quad \varphi(x,y)=0$$
